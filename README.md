# تنميات

تطبيق مجتمع تنموي عربي بواجهة تدعم الجوال، وواجهة برمجة تطبيقات، وقاعدة بيانات دائمة. يستخدم المشروع قاعدة SQLite عند تشغيله على Node.js، وD1 عند نشره على Cloudflare Workers. يشترك المساران في منطق الحسابات والنشر والإشراف وترحيلات قاعدة البيانات.

## التشغيل المحلي

يتطلب Node.js 24 أو أحدث. فك ضغط الحزمة وافتح الطرفية داخل المجلد الذي يحتوي على package.json.

```sh
npm start
```

افتح http://127.0.0.1:3000 . يُنشئ التطبيق قاعدة البيانات في data/tnmyat.sqlite ويضيف ثمانية موضوعات للنقاش عند التشغيل الأول. تعرض الرئيسية صفحة الترحيب. يفتح العضو الحائط من زر الدخول إلى المجتمع بعد التسجيل، ويعود إلى صفحة الترحيب عند الخروج. يفتح الضغط على الاسم أو الصورة قائمة الحساب. يفتح كل منشور على رابط مستقل. لتجربة الإشراف، سجل حسابًا عاديًا ثم رقّه من الطرفية.

```sh
npm run admin -- moderator@example.org
npm test
```

استبدل البريد ببريد الحساب الفعلي. حدّث الصفحة بعد الترقية. يمكن تجربة البلاغات من حساب ثانٍ. ينشئ الاختبار قاعدة مؤقتة مستقلة ويفحص مسارات العضوية والكتابة والصلاحيات واستمرار البيانات بعد إعادة تشغيل الخادم.

## الرفع إلى GitHub

أنشئ مستودعًا فارغًا ثم نفّذ الأوامر داخل مجلد المشروع بعد استبدال OWNER وREPOSITORY. أو ارفع الملفات عبر واجهة GitHub، بما فيها مجلدات src وpublic وmigrations.

```sh
git init
git add .
git commit -m "Initial Tnmyat community application"
git branch -M main
git remote add origin https://github.com/OWNER/REPOSITORY.git
git push -u origin main
```

يحفظ GitHub الشيفرة. يتطلب تشغيل الحسابات والنشر استضافة Worker أو خادم Node.js. يستبعد ملف .gitignore قاعدة البيانات المحلية.

## النشر على Cloudflare Workers + D1

نفّذ الأوامر داخل مجلد المشروع باستخدام حساب Cloudflare الذي سيملك التطبيق.

```sh
npx wrangler@4 login
npx wrangler@4 d1 create tnmyat-db
```

انسخ database_id الذي يعيده الأمر إلى wrangler.jsonc مكان المعرّف الصفري. إذا عرض Wrangler إضافة الربط تلقائيًا، اختر التعديل اليدوي لأن الملف يحتوي مسبقًا على ربط DB. عدّل name إذا أردت اسم Worker مختلفًا.

```sh
npm run db:remote
npm run deploy
```

افتح رابط workers.dev الذي يظهر بعد النشر. لنشر تحديث لاحق، طبّق الترحيلات الجديدة قبل النشر. يمكن ربط مستودع GitHub بمشروع Workers بعد ضبط معرّف القاعدة. يستخدم المشروع Workers Static Assets للواجهة وD1 للبيانات.

لترقية مشرف في القاعدة البعيدة بعد تسجيل حسابه عبر التطبيق، استبدل البريد في المثال الثابت ببريد الحساب.

```sh
npx wrangler@4 d1 execute tnmyat-db --remote --command="UPDATE users SET role='admin' WHERE email='moderator@example.org';"
```

## استضافة Node أو Docker

```sh
docker build -t tnmyat .
docker run --name tnmyat -p 3000:3000 -v tnmyat-data:/app/data -d tnmyat
```

افتح http://localhost:3000 . عند النشر على نطاق، ضع الخادم خلف وكيل HTTPS واضبط PUBLIC_ORIGIN على أصل الموقع الكامل مثل https://community.example.org. يتطلب تشغيل SQLite قرصًا دائمًا ونسخة خادم واحدة. يحتفظ حجم Docker المسمّى بالبيانات عند استبدال الحاوية. لنسخ قاعدة Node احتياطيًا أوقف الخادم ثم انسخ مجلد data كاملًا.

| المتغير | الاستعمال |
|---|---|
| PORT | منفذ Node، الافتراضي 3000 |
| HOST | عنوان الاستماع، الافتراضي 127.0.0.1 محليًا و0.0.0.0 في الحاوية |
| DB_PATH | مسار ملف SQLite على قرص دائم |
| PUBLIC_ORIGIN | الأصل الخارجي لخادم Node عند استخدام وكيل HTTPS |

## نطاق النسخة

**الحساب والشبكة.** يضم الملف الشخصي صورة العضو ونبذته ومؤشرات نشاطه. يستطيع العضو متابعة حساب آخر أو إرسال طلب صداقة، ومشاهدة الأعضاء النشطين حديثًا، وفتح محادثة خاصة. لتجربة العلاقات والرسائل محليًا افتح حسابين في متصفحين منفصلين.

**الحائط.** يدعم منشورات نصية قصيرة وموضوعات مطوّلة وتعديل منشوراتك وإرفاق صور أو فيديو MP4 أو صوت MP3 أو ملف PDF، والتعليق والإعجاب وإعادة النشر مع إسناد المشاركة إلى صاحبها. تبقى روابط الموضوعات المنشورة سابقًا صالحة بعد التحديث.

**المجموعات العامة.** ينشئ العضو مجموعة باسم ووصف. يستطيع الزائر قراءة نقاشاتها، ويستطيع العضو المشاركة بعد الانضمام. يدير المالك العضويات ويعيّن المشرفين، ويستطيع المشرف حذف مشاركة في نقاش مجموعته. النشر في المجموعة مستقل عن إرسال رسالة خاصة.

**تحديث تثبيت قائم.** يستخدم خادم Node ترحيلات تلقائية عند التشغيل، وعلى Cloudflare يُستخدم أمر db:remote قبل نشر الكود. يُنصح بالاحتفاظ بنسخة من قاعدة البيانات قبل التحديث. حسابات الأعضاء والرسائل في كل تثبيت تخص قاعدة بياناته. بيانات البداية تحريرية، وترحيل أرشيف الموقع الأصلي يحتاج إلى تصدير مستقل.
